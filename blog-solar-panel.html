UI Security, a well-regarded brand for Wi-Fi security cameras, now presents the S4 Max, a wired NVR (Network Video Recorder) system. This PoE (Power over Ethernet) system is designed to enhance your home security with wired reliability and comprehensive features.

What's Included in the S4 Max NVR Kit

The S4 Max NVR Kit includes an eight-channel NVR unit and four PoE PTZ cameras, ideal for medium to large home setups. Alongside these, the package contains mounting equipment, weatherproof connectors, Ethernet cables, and an HDMI cable for display connections.

Package Contents

  • ✅ Eight-channel NVR unit
  • ✅ Four PoE PTZ cameras (16-megapixel)
  • ✅ Mounting equipment for various surfaces
  • ✅ Weatherproof connectors
  • ✅ Ethernet cables for wired connections
  • ✅ HDMI cable for display connections

Setting Up the S4 Max System

Setting up the S4 Max involves downloading the UI app, creating an account, and using a setup wizard via an HDMI-connected monitor.

Installation Steps

  • 📱 Download the UI app and create your account
  • 🔌 Connect the NVR to your router to enable app control and remote access
  • 📹 Wire cameras to the NVR - provides both power and video transmission
  • 🔧 Position cameras using the provided mounts on various surfaces
  • 📺 Use HDMI connection to complete setup wizard on a monitor
Experts recommend running Ethernet cables first to ensure a clean setup.
